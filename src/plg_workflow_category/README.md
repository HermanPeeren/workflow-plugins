# Workflow Category plugin

A workflow plugin that allows setting a category change when a transition is executed for articles.

In the transition actions a category can be set.

This is an installable version of the core plugin that was proposed in [PR #45968 in Joomla CMS](https://github.com/joomla/joomla-cms/pull/45968) from August 23, 2025 by Dileep Adari. It is not generic, but com_content specific, according to some comments on January 31, 2026. 

This plugin was slightly edited used for the workflow of the User Guide and the Joomla Community Magazine.
