# workflow-plugins
Some custom plugins for Joomla's workflow. As examples for a Joomla Community Magazine article, edition June 2026, about custom Workflow plugins.

* [**Workflow Category**](src/plg_workflow_category) plugin: Dileep Adari's core PR as an installable plugin, to change categories during transitions.
* [**Workflow Notification Extended**](src/plg_workflow_notificationext): also send a notification to the original author.
* [**Workflow Revision**](src/plg_workflow_revision) plugin: edit a draft copy of an already published article.

You can find them under the /src directory.
